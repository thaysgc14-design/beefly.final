# Beefly
🚧 Status do Projeto: Em Desenvolvimento

## 💻 Tecnologias Aplicadas
O projeto utiliza as tecnologias fundamentais abordadas no curso para garantir portabilidade e segurança: 
- Java: Utilizado para o desenvolvimento da lógica de negócio, regras do sistema e interface desktop. 
- MySQL: Sistema de gerenciamento de banco de dados (SGBD) para armazenamento seguro e local das informações. JDBC (Java Database Connectivity): Para a integração entre a aplicação Java e o banco de dados MySQL. 
- Linguagem: Java (Lógica de negócio e interface).
- Banco de Dados: MySQL (Armazenamento local).
- Arquitetura: Aplicação Desktop Offline.

## 🚀 Diferenciais do Projeto
Operação Offline: O sistema funciona 100% localmente, garantindo que o salão opere sem interrupções, independente de conexão com a internet.Segurança de Dados: Utiliza MySQL local para armazenamento rápido e seguro, com sistema de backup diário enviado ao gerente.

## 🎯 Objetivo do Software
O BeeFly foi desenvolvido para atender às necessidades de salões de beleza, servindo para descomplicar a gestão diária e eliminar processos manuais. O objetivo central é unir todas as operações (agendamento, estoque, caixa e clientes) em um único sistema desktop que funcione 100% offline, garantindo que o negócio não pare por falta de internet.
